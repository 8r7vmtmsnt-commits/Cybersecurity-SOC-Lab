## Setup

- Ubuntu will run as SIEM
- Rocky will run as web server agent

  using Wazuh to establish host-based monitoring across a multi-OS environment.

## Deployment

Ubuntu will run wazuh manager and Rocky will run the wazuh agent

## Lab

used Kali Linux as an attacker node to perform reconnaissance (nmap) and authentication testing against the Rocky Linux target

the Ubuntu Wazuh manager successfully ingested the event logs and surfaced the security alerts.
